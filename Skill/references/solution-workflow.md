使用以下工作区结构：

```text
比赛工作区/

├── 数据/
├── 求解/
│   ├── 求解计划.md
│   ├── 方法调研.md
```

代码、图片、CSV 和 TeX 文件使用清晰的中文名称。用 `pathlib.Path` 组合路径，不要通过字符串相加构造路径。

## 读题和数据审计

完整读取 PDF/DOCX 题面。逐问提取：任务动词、输入、期望输出、约束、单位、评价标准、题目之间的依赖和提交物。

完整检查 CSV/XLS/XLSX/DOCX 附件：

- 文件编码、分隔符、工作表名称与隐藏状态；
- 行列数、列名、重复列、多级表头、合并单元格和备注行；
- 数值列中的文本、日期格式、单位不一致、缺失、重复和异常值；
- 主键或时间索引是否唯一、连续，表之间能否可靠关联。

输出简洁的数据总览。大文件不要把每一行打印到对话中，但必须通过程序全量扫描并保存异常摘要。

## 方法选择

先确定问题类型，再选择方法：

| 问题类型 | 常见候选 | 必要验证 |
|---|---|---|
| 优化 | 线性/整数规划、动态规划、启发式算法 | 可行性、约束满足、最优性界或多次运行稳定性 |
| 预测 | 统计时序、回归、树模型、神经网络 | 时间顺序切分、基线、外样本误差、残差 |
| 分类 | 逻辑回归、树模型、SVM、聚类后判别 | 类别不平衡、混淆矩阵、交叉验证 |
| 评价 | AHP、熵权、TOPSIS、模糊评价 | 权重敏感性、一致性、排名稳定性 |
| 机理 | 守恒方程、微分方程、仿真 | 量纲、边界条件、参数辨识和稳健性 |
| 描述分析 | 统计汇总、相关分析、分组比较 | 异常值影响、统计假设、效应量 |

不要只按“模型高级程度”、Kaggle 热度或论文引用数选择方法。先按 [research-and-promotion.md](research-and-promotion.md) 检索 Kaggle、论文和本地算法库，再通过统一实验决定。优先考虑问题匹配、可解释性、数据量、约束表达、可验证性和计算预算。至少提供一个简单基线；如果不适用，说明原因。

## 求解计划

在 `求解/求解计划.md` 中写清：

1. 题目总体方向与问题递进关系；
2. 每问的输入、输出、难点、候选来源、公平比较协议和选择规则；
3. 每问必须生成的数值、表格、图和验证结果；
4. 从加载、清洗、建模到输出的操作顺序；
5. 问题间数据流和中间文件；
6. 代码、图片、结果与论文文件清单；
7. 缺失数据、不收敛、样本过少、结果不稳定、网络不可用和候选无法复现等异常预案；
8. 计划沉淀到公共算法库的通用能力及验收条件。

## Python 实现

默认使用 pandas、NumPy、SciPy、scikit-learn 和 matplotlib。只有问题需要时才添加其他依赖。

按两个阶段组织脚本：

1. 纯计算：加载、预处理、建模、求解、验证并保存结构化结果。
2. 检查与绘图：输出关键统计量，读取已确定结果并生成图片。

至少做到：

- 使用 `matplotlib.use("Agg")` 支持无界面环境；
- 固定随机种子并记录模型参数；
- 保存 CSV 时使用 `utf-8-sig`；
- 图片保存为 PNG，通常使用 150–300 dpi 和 `bbox_inches="tight"`；
- 对关键数组检查形状、缺失值和有限性；
- 把中间数据与最终结果写入文件，不依赖 notebook 的执行顺序；
- 不全局屏蔽所有 warning；只处理已理解的特定 warning。

推荐的跨平台中文字体候选：

```python
plt.rcParams["font.sans-serif"] = [
    "Microsoft YaHei", "SimHei", "PingFang SC", "Hiragino Sans GB",
    "STHeiti", "Noto Sans CJK SC", "Arial Unicode MS", "DejaVu Sans",
]
plt.rcParams["axes.unicode_minus"] = False
```

保存函数使用路径连接：

```python
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
FIG_DIR = BASE_DIR / "图片"
OUT_DIR = BASE_DIR / "结果"
FIG_DIR.mkdir(parents=True, exist_ok=True)
OUT_DIR.mkdir(parents=True, exist_ok=True)

def save_fig(fig, name: str) -> None:
    fig.savefig(FIG_DIR / name, dpi=200, bbox_inches="tight")
    plt.close(fig)

def save_csv(df, name: str) -> None:
    df.to_csv(OUT_DIR / name, index=False, encoding="utf-8-sig")
```

## 图表原则

只生成能支持论证的图，避免同一信息重复可视化。优先使用柱状图表达类别对比、折线图表达时间趋势、散点图表达变量关系、热力图表达矩阵、箱线图表达分布差异。饼图仅用于类别很少且总和明确为整体的情形。

图内不设置总标题，由 LaTeX `\caption{}` 提供。坐标轴、刻度、图例必须完整且单位明确。使用色盲友好、打印可辨的配色；不要仅依赖颜色传达类别。

## 验证要求

- 预测问题采用符合时间顺序或分组结构的切分，禁止数据泄漏。
- 分类问题报告适合类别分布的指标，不只报告准确率。
- 优化问题逐条验证约束，并在适用时与下界、精确解或多次随机运行比较。
- 评价问题检查权重与排名对扰动的稳定性。
- 机理问题核对量纲、边界条件和参数可辨识性。
- 所有问题都区分训练内结果、外样本结果和假设情景结果。

若某种验证不适用，使用与问题结构相符的替代方案，并在论文中说明理由。
