# Axiom Lab 算法库

> 按问题类型分类、带来源与验证证据的可复用算法库。Skill 在求解前检索本库，在统一实验后把合格实现沉淀回来。

---

## 分类

| 目录 | 适用问题类型 | 典型算法 |
|------|------------|---------|
| `优化/` | 运筹优化、资源分配、路径规划 | 线性规划、遗传算法、模拟退火、蚁群算法 |
| `预测/` | 时间序列预测、回归预测 | ARIMA、LSTM、随机森林回归、灰色预测 |
| `分类/` | 模式识别、判别分析 | SVM、KNN、逻辑回归、随机森林分类 |
| `评价/` | 综合评价、决策分析 | TOPSIS、熵权法、层次分析法、模糊综合评价 |

## 算法包结构

每个算法使用独立目录：

```text
<分类>/<算法名>/
├── 算法实现.py
├── 最小示例.py
├── 测试.py
└── metadata.json
```

`metadata.json` 记录算法名称、分类、问题类型、入口文件、依赖、来源 URL、许可证、验证指标、验证日期和来源工作区。只有实际运行通过、可独立复用、来源与许可证清楚且包含最小示例和测试的实现才能入库。

根目录的 `算法索引.md` 由 Skill 的 `scripts/update_algorithm_index.py` 自动生成。未经验证的赛题脚本继续保留在比赛工作区的 `求解/` 中，不写入本库。
